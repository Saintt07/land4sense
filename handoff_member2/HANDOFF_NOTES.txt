WHAT IS IN THIS FOLDER
-----------------------
rf_landslide_model.joblib   — Trained Random Forest (scikit-learn)

PREPROCESSING PIPELINE (MUST DO THIS BEFORE CALLING EITHER MODEL)
------------------------------------------------------------------
When a user uploads a .h5 patch, your FastAPI /api/predict endpoint must:

STEP 0 — Stage 0 Guardrail (reject bad files):
    with h5py.File(uploaded_file, "r") as f:
        img = f["img"][()]              # shape must be (128, 128, 14)
    if img.shape != (128, 128, 14):
        return {"error": "Invalid format"}
    if img[:,:,9].mean() > 2.5:        # Band 10 Cirrus = index 9
        return {"error": "Excessive cloud cover"}

STEP 1 — Compute 3 spectral indices (14 → 17 channels):
    eps  = 1e-6
    ndvi = (img[:,:,7]  - img[:,:,3])  / (img[:,:,7]  + img[:,:,3]  + eps)
    ndwi = (img[:,:,2]  - img[:,:,7])  / (img[:,:,2]  + img[:,:,7]  + eps)
    bsi  = ((img[:,:,10] + img[:,:,3]) - (img[:,:,7] + img[:,:,1])) /            ((img[:,:,10] + img[:,:,3]) + (img[:,:,7] + img[:,:,1]) + eps)
    import numpy as np
    img17 = np.dstack([img, ndvi, ndwi, bsi]).astype(np.float32)
    # img17 shape is now (128, 128, 17)

STEP 2 — Normalize using channel_mean.npy and channel_std.npy:
    mean  = np.load("channel_mean.npy")   # shape (17,)
    std   = np.load("channel_std.npy")    # shape (17,)
    img17 = (img17 - mean) / std
    # img17 is now ready for both models

    import joblib

HOW TO LOAD AND RUN U-NET
---------------------------
    import torch
    import torch.nn as nn

    # U-Net architecture (paste the full UNet class from Step 7 here)
    model = UNet(in_channels=17)
    model.load_state_dict(torch.load("unet_landslide.pth", map_location="cpu"))
    model.eval()

    # Prepare input: HWC → CHW → add batch dim
    tensor = torch.from_numpy(img17.transpose(2,0,1)).unsqueeze(0)
    # tensor shape: (1, 17, 128, 128)

    with torch.no_grad():
        logits = model(tensor)                        # (1, 1, 128, 128)
        probs  = torch.sigmoid(logits).squeeze().numpy()  # (128, 128)
        unet_mask = (probs > 0.5).astype("uint8")    # (128, 128)

HOW TO GENERATE TRUE COLOR RGB PREVIEW (for map overlay)
----------------------------------------------------------
    import base64, io
    from PIL import Image

    rgb = img17[:, :, [3, 2, 1]]              # bands 4,3,2 = R,G,B (before norm)
    # Note: use the RAW img not img17 for RGB preview
    rgb_raw = img[:, :, [3, 2, 1]]
    rgb_norm = (rgb_raw - rgb_raw.min()) / (rgb_raw.max() - rgb_raw.min())
    rgb_uint8 = (rgb_norm * 255).astype("uint8")
    rgb_img = Image.fromarray(rgb_uint8, mode="RGB")

    buffer = io.BytesIO()
    rgb_img.save(buffer, format="PNG")
    rgb_b64 = base64.b64encode(buffer.getvalue()).decode("utf-8")
    # Send rgb_b64 in the JSON response → Member 3 uses this for the map overlay
