# Landslide4Sense Website — Complete Feature List

## 1\. Navigation \& Layout

* Top navigation bar with logo, menu links, and login button
* Mobile responsive hamburger menu
* Sticky header that stays visible while scrolling
* Footer with links, credits, and social media
* Breadcrumb navigation on inner pages
* Loading screen with animated logo on first visit
* Smooth page transitions between views
* Back to top button on long pages
* Skip to content accessibility link

## 3\. Main Hazard Map (View 1)

* 3D interactive map using Mapbox GL JS
* Satellite imagery base layer
* Street map base layer toggle
* Terrain 3D buildings layer toggle
* Pre-computed hazard zone overlay (Low / Moderate / High)
* Layer opacity slider for the hazard overlay
* Toggle hazard overlay on and off
* Click any hazard zone to show popup with details
* Popup shows risk level, affected area, coordinates, and date computed
* RGB satellite preview image inside the popup
* U-Net segmentation mask overlay inside the popup
* Slide-out hazard summary panel on the right side
* Upload `.h5` patch for live prediction at any location
* Drop a pin manually on the map to set prediction location
* Zoom in and out buttons
* Reset view button to return to default Philippines view
* Compass reset button
* Toggle between 2D flat and 3D tilted view
* Minimap in corner showing overview position
* Scale bar showing real-world distance
* Coordinate display showing current cursor lat/lon
* Philippine province boundary overlay toggle
* Municipality boundary overlay toggle
* Color legend fixed to bottom right corner
* Fullscreen mode button

## 4\. Search \& Location Features

* Search bar on the map accepting place names
* Search suggestions dropdown as you type
* Search by exact coordinates (lat, lon input fields)
* Search by province name from a dropdown list
* Search by municipality name
* Search history showing your recent searched locations
* Clear search history button
* Detect my current location button using browser geolocation
* Fly-to animation when a location is selected
* Highlight the searched area with a temporary ring
* Share a specific map view via URL with coordinates and zoom level encoded
